# Política de Privacidade

**e-Fatura Simples** (iPhone e Mac), Mesh Studios. Última atualização: 17 de outubro de 2026.

## Resumo

A aplicação não recolhe, não guarda e não partilha quaisquer dados pessoais connosco. Não existe nenhum servidor da Mesh Studios: a aplicação liga-se apenas ao Portal das Finanças.

## Credenciais

O NIF e a senha do Portal das Finanças ficam guardados apenas no seu dispositivo, no Porta-chaves (Keychain) do sistema. São enviados exclusivamente para o Portal das Finanças, para iniciar sessão, tal como acontece quando usa o site num navegador.

## Faturas e dados fiscais

As faturas, deduções e restantes dados são lidos do Portal das Finanças e mostrados na aplicação. As alterações que fizer (classificar ou registar faturas) são enviadas diretamente para o Portal das Finanças. A situação fiscal que indicar no Perfil (agregado, dependentes, rendimento, habitação) fica apenas no dispositivo e serve só para calcular os limites das deduções.

## Câmara

A câmara é usada apenas para ler o código QR de uma fatura quando escolhe registá-la. Nenhuma imagem é guardada ou enviada.

## Exportação

O ficheiro CSV de faturas é preparado no próprio dispositivo e só sai dele quando o partilha, para onde escolher.

## Publicidade, análise e rastreamento

A aplicação não tem publicidade, não usa ferramentas de análise e não faz rastreamento.

## Apagar os dados

Remover uma conta no Perfil apaga a senha guardada dessa conta. Apagar a aplicação remove todos os dados do dispositivo.

## Aviso

e-Fatura Simples é uma aplicação independente. Não é afiliada nem endossada pela Autoridade Tributária e Aduaneira.
